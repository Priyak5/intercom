What this page is for

This is a plain HTML page served from a different origin than the support app. The one <script> tag below installs the chat widget. Open it, send a message, refresh — the transcript persists.

How to point it at your instance

Replace data-key with your workspace's public_key (from /api/auth/me or the dashboard). Replace data-endpoint with the URL of your deployed app (e.g. https://app.example.com). For local testing, omit data-endpoint and serve this page from any HTTP server whose origin differs from the app's (python -m http.server 5500 in this directory works).

Cross-origin note: the loader will fetch /api/widget/config and open an iframe against data-endpoint. The widget endpoints answer with permissive CORS since no cookies are used — only a signed token in a header.
